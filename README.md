# ارزش‌سنج

وب‌اپ دسکتاپ فارسی برای محاسبه ارزش تضمینی، خرید با اعتبار و تبدیل دارایی‌ها. فرانت‌اند Angular و بک‌اند Django هستند؛ داده‌ای ذخیره نمی‌شود و نرخ‌ها فقط در حافظه صفحه هر کاربر نگهداری می‌شوند. تصاویر موجود در ریشه پروژه نمونه مرجع رابط هستند.

## اجرا

نیازمندی‌ها: Python 3.9 یا بالاتر و Node.js و npm. در دو پایانه جداگانه از ریشه پروژه:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python backend/manage.py runserver 127.0.0.1:8000
```

```bash
cd frontend
npm install
npm start
```

صفحه `http://127.0.0.1:4200` را باز کنید. سرور توسعه Angular درخواست‌های `/api` را به Django هدایت می‌کند. برای ساخت فرانت‌اند `cd frontend && npm run build` و برای تست `python backend/manage.py test calculator` را با محیط مجازی فعال اجرا کنید.

## ساختار و فرض‌ها

- `backend/calculator/finance.py`: منطق مستقل، با دقت Decimal برابر ۵۰ رقم معنادار و بدون گرد کردن میانی عمدی. API نتایج را به شکل رشته اعشاری تومان برمی‌گرداند. رابط نتیجه را تقریبی، با حداکثر دو رقم اعشار نشان می‌دهد.
- `backend/calculator/views.py`: API بدون وضعیت `POST /api/calculate/`؛ نرخ‌ها و مقادیر به صورت رشته و درصد نرخ به صورت عددی مانند `44` ارسال می‌شوند.
- `frontend/src/app`: رابط و فرم‌ها. تغییر واحد صرفاً تفسیر تمام ورودی‌های مبلغ را تغییر می‌دهد؛ مقدارهای واردشده را تبدیل نمی‌کند.
- نرخ‌های پیش‌فرض طلا، سهام و درآمد ثابت به ترتیب ۴۴، ۵۵ و ۶۰٫۵ درصد هستند؛ هر نرخ مستقل و قابل تغییر است.
- در محاسبه مستقیم سقف اعتبار `سرمایه × نرخ / (۱ − نرخ)` و در معکوس `ارزش هدف × نرخ` است. درصد مصرف نسبت به سقف متناظر محاسبه می‌شود.
- در تبدیل مستقیم کل مبدأ فروخته و کل بدهی آن تسویه می‌شود. در تبدیل معکوس کاربر ارزش کل و بدهی مبدأ و مبلغ تسویه را مشخص می‌کند؛ فروش برابر سرمایه خالص موردنیاز به‌علاوه مبلغ تسویه است. اعتبار باقی‌مانده باید با دارایی باقی‌مانده پوشش داده شود. دارایی و اعتبار مقصد جداگانه محاسبه می‌شوند؛ از ظرفیت تضمینی مقصد برای پوشش بدهی مبدأ استفاده نمی‌شود.
- اعتبار جدید فقط برای خرید مقصد به کار می‌رود. فروش کسری مجاز است. کارمزد، مالیات، تغییر قیمت و محدودیت‌های عملیاتی صفر فرض شده‌اند. نرخ باید حداقل صفر و کمتر از ۱۰۰٪ و ارقام غیرمنفی باشند.
- این تنظیمات برای اجرای محلی توسعه در نظر گرفته شده‌اند و پیکربندی استقرار عمومی نیستند.
